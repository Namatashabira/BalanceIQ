# Hero Banners - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### Step 1: Open Website Builder
1. Navigate to Website Builder page
2. You'll see the canvas editor

### Step 2: Add a Hero Banner
1. Click on "Blocks" tab in left sidebar
2. Drag a hero banner template to canvas
3. Choose from:
   - Marketing Hero (two-column layout)
   - Centered Hero (SaaS-style)
   - Cover Banner (full-width background)

### Step 3: Select & Edit
1. Click on the hero banner
2. Blue border appears (selected)
3. Now you can drag, resize, and edit

### Step 4: Drag Elements
1. Hover over any element (text, button, image)
2. "Drag" handle appears at top-left
3. Click and drag to move anywhere
4. Release to drop

### Step 5: Resize Elements
1. Hover over any element
2. Resize handle appears at bottom-right
3. Click and drag to resize
4. Release to set new size

---

## 📝 Editing Content

### Edit Text
```
1. Click on text
2. Text becomes editable
3. Type to change content
4. Click outside to finish
```

### Edit Button
```
1. Click on button
2. Text input appears
3. Edit button text
4. Click button to open styling toolbar
5. Customize colors, size, padding
6. Click "Done" to finish
```

### Replace Image
```
1. Select hero banner
2. Hover over image
3. URL input appears
4. Paste new image URL
5. Image updates automatically
```

## 🎯 Common Tasks

### Task: Create Two-Column Layout
```
1. Drag headline to left (x: 20, y: 20)
2. Drag button below headline (x: 20, y: 160)
3. Drag image to right (x: 450, y: 20)
4. Resize image to fit
5. Done!
```

### Task: Center All Elements
```
1. Drag headline to center (x: 0, y: 50)
2. Drag button to center (x: 0, y: 200)
3. Drag image to center (x: 0, y: 280)
4. Resize image to fit
5. Done!
```

### Task: Full-Width Background
```
1. Use CoverBanner template
2. Replace background image
3. Drag headline to desired position
4. Drag button to desired position
5. Adjust overlay opacity
6. Done!
```

## 🔧 Troubleshooting

### Element won't drag?
**Solution**: 
- Make sure hero banner is selected (blue border)
- Hover to see drag handle
- Try clicking the drag handle directly

### Button navigates instead of editing?
**Solution**:
- Make sure hero banner is selected
- Click the button, not the text
- Check that you're in edit mode

### Image not displaying?
**Solution**:
- Check image URL is valid
- Verify CORS is enabled
- Try a different image URL

### Changes not saving?
**Solution**:
- Click outside to deselect
- Reselect to verify changes
- Check browser console for errors
