# Hero Banners - Canva-Like Inline Editing Guide

## Overview

Hero banners now feature Canva-like inline editing where all text and buttons are directly editable on the canvas, just like Canva.com. No need to open settings panels - click, edit, and style everything in place.

## Key Features

### ✨ **Direct Text Editing**
- Click any text to edit directly
- Type, delete, add, remove text
- Press Enter to create line breaks
- No modal dialogs needed

### 🎨 **Floating Toolbar**
- Appears when text is selected
- Font size control (8-100px)
- Bold/Italic toggle
- Text color picker
- Background color option
- Add links to text

### 🔘 **Editable Buttons**
- Click button to edit text
- Floating toolbar for styling
- Font size control
- Padding adjustment
- Border radius control
- Text and background colors
- Add links to buttons

### 📐 **Real-Time Preview**
- See changes instantly
- No save button needed
- Responsive to all devices

## How to Use

### Editing Text

#### Step 1: Click on Text
```
1. Click on any text in hero banner
2. Text becomes editable (blue dashed outline)
3. Cursor appears in text field
```

#### Step 2: Edit Content
```
1. Delete existing text
2. Type new text
3. Press Enter for line breaks
4. Click elsewhere to finish
```

#### Step 3: Style Text
```
1. Select text by highlighting
2. Floating toolbar appears above
3. Adjust font size with slider
4. Toggle bold/italic
5. Choose text color
6. Add background color
7. Click "Done"
```

### Editing Buttons

#### Step 1: Click on Button
```
1. Click on button in hero banner
2. Button becomes editable
3. Text input field appears
4. Floating toolbar appears
```

#### Step 2: Edit Button Text
```
1. Type new button text
2. Changes apply instantly
3. Button updates in real-time
```

#### Step 3: Style Button
```
1. Click on button to show toolbar
2. Adjust font size
3. Change padding (X and Y)
4. Adjust border radius
5. Choose text color
6. Choose background color
7. Add link URL
8. Click "Done"
```
