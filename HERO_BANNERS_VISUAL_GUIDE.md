## How It Works

### Step 1: Select Hero Banner
```
Click on hero banner → Blue border appears
```

### Step 2: Drag Elements
```
Hover over element → "Drag" handle appears
Click and drag → Element moves
Release → Element drops in new position
```

### Step 3: Resize Elements
```
Hover over element → Resize handle appears (bottom-right)
Click and drag → Element resizes
Release → Element size updates
```

### Step 4: Edit Text
```
Click on text → Text becomes editable
Type → Content changes
Click outside → Editing stops
```

### Step 5: Edit Button
```
Click on button → Text input appears
Edit text → Button text changes
Click button → Styling toolbar opens
Customize → Colors, size, padding, etc.
```

## Troubleshooting

### Element won't drag?
- Make sure hero banner is selected (blue border)
- Hover to see drag handle
- Try clicking the drag handle directly

### Resize handle not visible?
- Hover over the element
- Make sure hero banner is selected
- Check bottom-right corner

### Button navigates instead of editing?
- Make sure hero banner is selected
- Click the button, not the text
- Check that you're in edit mode

### Image not displaying?
- Check image URL is valid
- Verify CORS is enabled
- Try a different image URL
