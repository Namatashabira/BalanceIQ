# Hero Banners - Canva-Like Editing Quick Start

## 🚀 Getting Started

### Access Website Builder
1. Go to `/website-builder`
2. Or click "Website Builder" in sidebar

### Add Hero Banner
1. Click "Blocks" tab
2. Drag hero banner to canvas
3. Click to select

## ✏️ Edit Text Like Canva

### Click to Edit
```
1. Click on any text
2. Text becomes editable
3. Cursor appears
4. Start typing
```

### Delete & Replace
```
1. Click text
2. Select all (Ctrl+A)
3. Delete
4. Type new text
```

### Add Line Breaks
```
1. Click text
2. Position cursor
3. Press Enter
4. New line created
```

### Style Text
```
1. Click text
2. Highlight text
3. Floating toolbar appears
4. Adjust font size
5. Toggle bold/italic
6. Choose colors
7. Click "Done"
```

## 🔘 Edit Buttons

### Click to Edit
```
1. Click button
2. Text input appears
3. Type new text
4. Changes apply instantly
```

### Style Button
```
1. Click button
2. Floating toolbar appears
3. Adjust font size
4. Change padding
5. Adjust border radius
6. Choose colors
7. Add link
8. Click "Done"
```

## 🎨 Styling Options

### Font Size
- Slider: 8-100px

### Text Effects
- Bold: Toggle on/off
- Italic: Toggle on/off
- Color: Full color picker
- Background: Optional

### Button Styling
- Font size: 8-32px
- Padding X: 4-48px

- Background color

### Links
- Click "Add Link"
- Enter URL

## 📋 Common Tasks

### Change Headline
```
1. Click headline
2. Select all (Ctrl+A)
3. Type new headline
4. Highlight text
5. Increase font size
6. Make bold
7. Choose color
8. Click "Done"
```

### Make Text Larger
```
1. Click text
2. Highlight text
3. Drag font size slider right
4. Or type exact size
5. Click "Done"
```

### Change Text Color
```
1. Click text
2. Highlight text
3. Click color picker
4. Choose color
5. Click "Done"
```

### Add Bold Text
```
1. Click text
2. Highlight text
3. Click "Bold" button
4. Text becomes bold
5. Click "Done"
```

### Style Button
```
1. Click button
2. Floating toolbar appears
3. Adjust font size
4. Change padding
5. Choose colors
6. Click "Done"

### Add Button Link
```
1. Click button
2. Click "Add Link"
