## 🚀 How to Use

### Add Hero Banner
1. Go to `/website-builder`
2. Click "Blocks" tab
3. Drag hero banner to canvas
4. Click to select

### Edit Text
1. Click on text
2. Type to edit
3. Highlight text
4. Floating toolbar appears
5. Adjust styles
6. Click "Done"

### Edit Button
1. Click button
2. Edit text in input
3. Click button again
4. Floating toolbar appears
5. Adjust styles
6. Click "Done"

### Upload Image
1. Click hero banner
2. Click "Advanced Settings"
3. Click "Upload"
4. Select image
5. Image loads
